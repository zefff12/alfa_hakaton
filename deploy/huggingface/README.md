# Умный кредитный кабинет предпринимателя · Альфик

Публичное демо проекта хакатона Альфа-Банка. Исходный код, документация и запуск через
`docker compose`: https://github.com/zefff12/alfa_hakaton

**Вход:** на экране входа выберите тестовую компанию («Демо-доступ»), пароль у всех — `demo`.
Сотрудник банка (консоль андеррайтера) — логин `underwriter`.

Все компании, документы и условия — синтетические. Внешние сервисы (ЕГРЮЛ, ФНС, БКИ) —
моки внутри контейнера. Демо-данные создаются заново при каждом перезапуске Space.

Этот Space собирается из двух файлов (`Dockerfile`, `README.md`) из папки
[`deploy/huggingface`](https://github.com/zefff12/alfa_hakaton/tree/main/deploy/huggingface):
код берётся из GitHub при сборке. Чтобы выложить свежую версию, нажмите в настройках Space
**Factory rebuild**.
