# Тестовые сценарии

Тестовые учётные записи создаются автоматически при первом запуске. Пароль у всех — `demo`. Все компании, ИНН и финансовые показатели синтетические.

| Логин | Компания (ИНН) | Что демонстрирует |
|---|---|---|
| `kolosok` | ООО «Колосок», пекарня (7701234561) | Автоматическое одобрение → подписание → выдача |
| `flora` | ИП Смирнова, цветочный магазин (772012345678) | Контрпредложение: банк предлагает безопасную сумму / срок |
| `stroy` | ООО «СтройМонтаж Плюс» (7703456789) | Запрос документов → ручное рассмотрение андеррайтером |
| `romashka` | ООО «Ромашка Трейд» (7704567890) | Отказ по стоп-фактору с объяснением |
| `failover` | ООО «Тест Отказоустойчивость» (7700000000) | БКИ недоступно → конвейер не падает, заявка уходит специалисту |
| `underwriter` | — | Консоль андеррайтера |

Можно зарегистрировать нового клиента с **любым** ИНН из 10/12 цифр — симулятор ЕГРЮЛ/ФНС/БКИ детерминированно сгенерирует для него данные.

## Сценарий 1. Сквозной путь до выдачи (kolosok) — основной

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Войти как «ООО «Колосок»» на вкладке «Демо-доступ» | Главная с приветствием Альфика, лента под общепит |
| 2 | «Подобрать кредит» → цель «Пополнить оборотные средства» → 3 000 000 ₽ → 24 мес. → «Нет залога» → «Могу подождать» | Список продуктов с % совпадения и объяснением «почему»; лучший — оборотный кредит |
| 3 | Выбрать «Кредит на пополнение оборотных средств», подвигать ползунки | Платёж, переплата и итог пересчитываются |
| 4 | Нажать «Платёж слишком высокий для меня», ввести 100 000 → «Подобрать условия» | Варианты: больше срок / меньше сумма; клик применяет вариант |
| 5 | «Оформить заявку» | Черновик, шаг «Параметры»; «✓ Черновик сохранён» |
| 6 | Шаг «Компания» | Реквизиты из ЕГРЮЛ с бейджем «Данные из ЕГРЮЛ» — вводить не нужно |
| 7 | Шаг «Финансы»: выручка 4 500 000, расходы 3 600 000, платежи 180 000 | Свободный поток, платёж и долговая нагрузка считаются на лету |
| 8 | Шаг «Отправка»: два согласия → «Отправить заявку в банк» | Статус «Заявка отправлена»; подэтапы проверки отмечаются в реальном времени |
| 9 | Подождать ~10 сек | «Одобрено», карточка предложения |
| 10 | «Принять и перейти к подписанию» | Экран подписания, код ПЭП показан в кабинете |
| 11 | Ввести код → «Подписать договор» | «Выдача средств» → «Средства выданы», номер договора, счёт, график из 24 платежей |
| 12 | Колокольчик | Уведомления о каждом ключевом статусе |

## Сценарий 2. Каковы мои шансы? + контрпредложение (flora)

1. «Мои шансы»: Экспресс-кредит, 3 000 000 ₽, 12 мес., бизнес 26 мес., выручка 800 000, расходы 600 000, платежи 15 000 → **средняя готовность**, факторы «помогает / мешает», совет «комфортная сумма до …», дисклеймер.
2. «Оформить заявку с этими данными» — анкета уже заполнена.
3. Согласия → отправить → через ~10 сек **«Предложены другие условия»** с двумя вариантами (больше денег на 36 мес. / меньшая сумма на 12 мес.). Выбрать вариант → подписание.

## Сценарий 3. Документы и андеррайтер (stroy + underwriter)

1. Оборотный кредит **15 000 000 ₽ на 36 мес.**, выручка 10 000 000, расходы 7 500 000, платежи 520 000, без документов → отправить.
2. Этап проверки данных: **«Нужны документы»** — выписка (сумма > 5 млн). Загрузить любой PDF → «Отправить повторно».
3. Скоринг: налоговый долг 64 тыс. по ФНС → снова **«Нужны документы»** — справка из ФНС. Загрузить → отправить.
4. **«Рассматривает специалист»**: сумма выше лимита автоматики 10 млн.
5. Выйти, войти как `underwriter` → очередь «Ручное рассмотрение» → карточка: сверка «со слов клиента vs источники», ЕГРЮЛ/ФНС/БКИ, разбор скоринга, правила, рекомендация движка.
6. «Изменить условия» → 12 000 000 ₽ → комментарий → «Зафиксировать решение».
7. Войти как `stroy` → заявка в статусе «Предложены другие условия» с условиями специалиста.

## Сценарий 4. Отказ с объяснением (romashka)

Экспресс-кредит 500 000 ₽ → отправить → **«Отказ»**: «По данным ЕГРЮЛ компания в процессе ликвидации». Альфик предлагает проверить шансы / подобрать другой продукт.

## Сценарий 5. Отказоустойчивость (failover)

Любая заявка → на этапе запроса сведений БКИ отвечает 503 → после ретраев заявка уходит **специалисту**, в истории — событие `INTEGRATION_ERROR`. Дополнительно: `MOCK_FAILURE_RATE=0.3` в `.env` включает случайные сбои всех источников.

## Сценарий 6. Персональная лента и Альфик

1. Сравнить «Ленту Альфика» у `kolosok` (общепит: оборудование для пекарни, сезонная закупка) и `stroy` (строительство: кассовые разрывы, тендеры). Каждая карточка объясняет «почему вы это видите».
2. Отправить заявку — лента меняется под этап («Ваша заявка в работе…»), после выдачи — советы заёмщику.
3. «Не интересно» — карточка исчезает; «Полезно» — похожие темы поднимаются выше.
4. Чат Альфика: «Какой статус заявки?», «Какие нужны документы?», «Почему отказ?», «Платёж слишком высокий» — ответы с данными конкретной заявки и кнопками-действиями.

## Сценарий 7. «Расскажите Альфику» — заявка из рассказа (kolosok)

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Меню «Рассказать Альфику» (или кнопка 🎙 на главной) | Альфик просит рассказать задачу своими словами, есть примеры фраз |
| 2 | Написать (или сказать в микрофон 🎙 — Edge/Chrome): «Нужно 2 млн на новую печь, верну за 3 года, выручка около 4,5 млн в месяц» | Карточка справа заполняется: сумма, цель, срок, выручка; у каждого поля — фраза-источник; возраст бизнеса подтянут из ЕГРЮЛ; Альфик спрашивает про расходы |
| 3 | «примерно 3,6 млн» → «плачу 180 тысяч в месяц по кредиту на оборудование» → «да, сама печь» | Короткие ответы отнесены к заданным вопросам (расходы, текущие кредиты, залог) |
| 4 | — | Подобран инвестиционный кредит, платёж и готовность к подаче; кнопка «Создать черновик заявки» активна |
| 5 | «Создать черновик заявки» | Черновик с продуктом, суммой, сроком, залогом и финансами — повторно вводить ничего не нужно |
| 5а | Документы: коммерческое предложение (любой PDF) и `vypiska_kolosok_1c.txt` → отправить | Выписка подтверждает выручку; после проверки — «Одобрено». Если в рассказе занизить выручку или «забыть» кредит, который виден в БКИ, банк посчитает по фактическим данным |
| 6 | В обычном чате Альфика написать «хочу взять 3 млн на закупку товара» | Альфик предлагает «Собрать заявку из рассказа» и переносит текст на экран диалога |

## Сценарий 8. Альфик читает выписку (stroy + underwriter)

1. Создать заявку «СтройМонтаж»: оборотный кредит 15 млн на 36 мес., выручка **13 000 000** (завышена), расходы 7 500 000, платежи 520 000.
2. Шаг «Документы» → «Нет выписки под рукой? Скачайте пример» → `ООО «СтройМонтаж Плюс» — 1С` → загрузить как «Выписка по расчётному счёту».
3. Появляется карточка «Альфик прочитал выписку»: график по месяцам, очищенные поступления ≈ 9,5 млн/мес, «⚠ выписка ниже (−27%)», флаг «зависимость от одного покупателя (АО «ГК Девелопмент») 59%», кнопка «Подставить выручку из выписки».
4. Загрузить справку ФНС (любой PDF), отправить. Скоринг использует обороты по выписке, заявка уходит специалисту (сумма > 10 млн).
5. `underwriter` → карточка: **«Резюме Альфика»** (расхождение анкеты и выписки, концентрация покупателя, налоговый долг, рекомендация движка, что проверить), разбор выписки с топом плательщиков, строка «Выручка в мес. (выписка)» в сверке.

Для «Колосок» загрузите `vypiska_kolosok_1c.txt` или `vypiska_kolosok.csv`: оба формата дают одинаковый результат, а перевод со своего счёта и займ учредителя (1,3 млн) исключаются из выручки.

## Сценарий 9. Английский и китайский

1. На экране входа или в шапке переключить язык на **EN** или **中文** (выбор запоминается).
2. Войти как `kolosok`: интерфейс, продукты, статусы, подсказки Альфика и лента — на выбранном языке; суммы — в формате `₽3,000,000`.
3. «Tell Alfik» / «告诉 Alfik»: написать (или сказать голосом) `I need 2 million for a new oven, will repay in 3 years, revenue around 4.5 million a month` или `需要200万买新烤炉，3年还清，每月营业额450万左右` → карточка заполняется, вопросы Альфика — на том же языке.
4. Отправить заявку → история, решение, уведомления — на выбранном языке.
5. Войти как `underwriter` с языком EN: консоль банка остаётся на русском (внутренний инструмент).

## Сценарий 10. Кредитный подбор: свайпы, избранное, сравнение (flora)

1. «Кредитный подбор» → выбрать, что важнее (например, «Скорость получения») — первой идёт карточка экспресс-кредита.
2. Перетащить карточку вправо (или «В избранное», или клавиша →) — счётчик «Избранные» в меню растёт; влево / «Пропустить» / ← — карточка уходит.
3. После 2–3 выборов появляется подсказка «Похоже, для вас важнее…» — колода перестроена.
4. Фильтры «Цель / Сумма / Срок / Залог / Важнее» и «Изменить параметры» (мастер из 4 шагов) пересчитывают предложения.
5. «Сравнить предложения» → таблица из 11 строк, лучшие значения подсвечены зелёным; «Оформить заявку» создаёт черновик.
6. Нажатие на карточку → «Подробнее»: ползунки суммы и срока пересчитывают платёж, «Добавить в избранное», «Оформить заявку».

## Сценарий 11. Альфик находит ошибки в документах (kolosok)

1. Создать черновик «Кредит на пополнение оборотных средств», в анкете выручка 4,5 млн/мес.
2. «Документы» → выбрать заявку → загрузить `vypiska_oshibka_chuzhaya_1c.txt` (скачивается в блоке «Нет выписки под рукой?»): ошибка «Выписка принадлежит другой компании», источники — «Выписка 1С» и «ЕГРЮЛ».
3. Загрузить `vypiska_oshibka_2_mesyaca_1c.txt` → предупреждение «Полных месяцев в выписке: 2 — нужно 6».
4. Загрузить `vypiska_oshibka_nizkie_oboroty_1c.txt` → «Поступления по выписке на 65% ниже выручки в анкете», значения из анкеты и выписки рядом; кнопка «Указать 1 556 087 ₽ из выписки» исправляет анкету, проверка становится зелёной, в истории — «Клиент исправил анкету по подсказке Альфика».

## Сценарий 12. Задача от банка и автоматическая смена статуса (stroy)

1. Заявка на 15 млн без выписки → шкала: ✓ Анкета заполнена, ! Данные проверены — «Нужны документы — задача ниже»; в блоке «Ваши задачи» — «Загрузите: Выписка по расчётному счёту за 6 месяцев».
2. «Загрузить» ведёт в «Документы» к нужной строке; после загрузки заявка сама уходит дальше (в истории: «Все запрошенные документы загружены — заявка автоматически отправлена дальше»).
3. Банк просит справку об уплате налогов → на шкале «Проверка финансовых показателей» отмечена вниманием, новая задача в кабинете.
